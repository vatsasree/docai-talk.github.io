# Project-page QR codes

Drop four PNGs here, named exactly as below. They appear on the closing slide,
each under its paper name. Any that is missing simply doesn't show, so you can
add them one at a time.

| File | Paper | Encode this URL |
|---|---|---|
| `replica.png`     | REPLICA      | https://replica-agents.github.io |
| `m3grounder.png`  | M3Grounder   | https://m3grounder.github.io |
| `docog.png`       | DoCoG        | https://docog-eccv.github.io |
| `doclayoutvl.png` | DocLayout-VL | https://doclayoutvl.github.io |

Square PNG, quiet border included, ~600×600 is plenty. Black on white reads
best from the back of a room. No rebuild needed after adding them.
